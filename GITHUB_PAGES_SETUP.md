# Publish UI/UX portfolio to Angie22-dev/UIUX-Projects

Repository: https://github.com/Angie22-dev/UIUX-Projects

This package places `index.html` in the repository root so GitHub Pages can publish it without a build step.

1. Extract the ZIP. Open index.html in a text editor and replace the placeholder `https://www.linkedin.com/in/marla-singleton-94421023a/` with your LinkedIn profile. Remove the `setup-warning` paragraph after doing so.
2. Confirm all visuals can be shown publicly, and verify employer dates and claims.
3. In https://github.com/Angie22-dev/UIUX-Projects, select **Add file → Upload files** (or the initial **uploading an existing file** link if the repo remains empty).
4. Upload **the contents of the extracted folder** (index.html, styles.css, script.js, assets folder and so on), not the ZIP itself. Ensure images appear under `assets/`.
5. Commit to `main`.
6. Open **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
7. The expected Pages URL is https://angie22-dev.github.io/UIUX-Projects/ (only live after enabling Pages and deployment).

For Netlify, upload the same extracted folder to https://app.netlify.com/drop . GitHub and Netlify can host the same static files.
