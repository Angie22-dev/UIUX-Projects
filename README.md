# Angelica Singleton — UI/UX Portfolio

A responsive, static portfolio site showcasing two UI/UX case studies:
- Cloudhire Talent Portal
- Zeneith Insurance Renewal (desktop and mobile)

## Before publishing (required)
1. Open `index.html` and replace the generic ``https://www.linkedin.com/in/marla-singleton-94421023a/` links with your **actual profile URLs**.
2. Remove the visible "Before publishing" reminder paragraph (`id="setup-warning"`).
3. Check project descriptions and personally verify claims about your work and ownership. Do not claim usability studies or measurable improvements that weren't completed.
4. Review all images before publishing. The provided versions have personal-detail areas covered, but verify that no other private client or customer information remains. Confirm you have permission to display project visuals.
5. Check your site on a phone and desktop. Test navigation and keyboard focus.

## Netlify deployment
1. Extract this ZIP.
2. Go to Netlify > Add new project > Deploy manually.
3. Drag the **medavize_portfolio folder** containing `index.html` onto Netlify Drop.
4. Your site is live; rename the site address if desired.

## GitHub Pages deployment
1. Use the existing `Angie22-dev/UIUX-Projects` repository.
2. Upload the **contents** of this folder to the root of the repository.
3. Settings > Pages > Build and deployment > Deploy from a branch > `main` / `(root)`.
4. Open the published Pages URL after deployment completes.

## Site structure
`index.html` content; `styles.css` responsive styling; `script.js` footer year; `assets/` the uploaded project screenshots with light privacy redaction.

Fonts load via Google Fonts; system fallbacks are provided. No framework or build step needed.
